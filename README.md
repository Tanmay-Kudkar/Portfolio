# Portfolio Website

A modern, responsive portfolio website that presents a developer's skills, education, and selected projects in a clean one-page layout.

## Overview

This repository contains a static portfolio site built to showcase professional experience, technical skills, and project highlights. It is intended as a personal web presence for recruiters, collaborators, and anyone reviewing the developer's work.

## What This Repository Is For

- Showcasing education and technical background
- Presenting selected full-stack and SaaS-style projects
- Providing a polished, responsive personal website
- Demonstrating front-end design, layout, and interaction skills

## Features

- Responsive single-page layout
- Hero section with short professional summary
- About / career objective section
- Education timeline
- Skills section with technical and professional tags
- Project cards with GitHub and live demo links
- Contact section with direct email and phone actions
- Smooth section navigation
- Scroll-based reveal animation
- Modern UI with gradients, glassmorphism, and rounded cards

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts: Space Grotesk and Inter

## Getting Started

This is a static website, so there is no build step or dependency installation required.

### Open Locally

Open `index.html` directly in a browser or use VS Code Live Server for local preview.

## Customization

Edit these files to adapt the portfolio:

- `index.html` for content, sections, and external links
- `styles.css` for layout, color, typography, and responsiveness
- `script.js` for reveal animations or other small interactions

## Deployment

Because this is a static front-end project, it can be deployed easily to platforms such as Vercel, Netlify, GitHub Pages, or Render static hosting.
